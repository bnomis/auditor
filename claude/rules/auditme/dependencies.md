# Python dependency management

All dependencies are declared in `pyproject.toml` and managed via
[`uv`](https://docs.astral.sh/uv/). The `uv.lock` file is committed for
reproducibility.

Before adding a new dependency, run through the checks in
`~/.claude/rules/tools-and-libraries.md` (prefer what's
already in the project, verify maintenance status).

## Commands

- Add: `uv add <package>` (runtime dep)
- Add dev: `uv add --dev <package>` (test/lint/build tools)
- Add to optional group: `uv add --optional <group> <package>`
- Remove: `uv remove <package>`
- Upgrade one: `uv lock --upgrade-package <package>`
- Sync the venv to the lockfile: `uv sync`

Do not run `pip install` - it bypasses the lockfile and produces an
inconsistent venv.

## The lockfile

`uv.lock` is generated by `uv` and committed to the repo. Do not
hand-edit it - changes will be clobbered on the next `uv` invocation.

If `uv` reports a resolver conflict, share the output with the user
rather than silently downgrading or removing a constraint.

## Python version

The interpreter version is pinned via `.python-version` / `pyproject.toml`'s
`requires-python`. Use `uv python pin <version>` to change it.
