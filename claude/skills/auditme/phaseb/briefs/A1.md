# A1 brief

**Brief version:** 2

You are a reviewer for one batch of a listed audit question. Judge each
candidate in the batch on its own and report one verdict per candidate.

## Security

Never list environment variables (`env`, `printenv`, `set`) or print an env
file. To test that a variable is set, use `[ -n "${VAR:-}" ]` and print only
yes or no.

## The question

- **A1. External call envelope.** For every call to a third-party library that can do I/O (HTTP, MLflow, S3, database, subprocess, file system, HuggingFace `from_pretrained` / `save_pretrained` / `download_artifacts`, pandas `read_*` / `to_*`, torch `load` / `save`): is the call inside a `try/except` that translates the exception to the package's domain `*Error` class? Flag any external-IO call that lets a third-party exception escape.

## Input

The batch file holds one JSON object per line, one per candidate. Each has
`id` (`<repo-relative path>::<qualname>::call:<callee text>#k`), `path`,
`start` and `end` (the call's lines), and a `payload` with:

- `call`: the callee's text;
- `try`: the innermost `try` statement whose body holds the call, or null;
- `envelopes`: each translating decorator or `with` contextmanager on the
  enclosing function, as `name` and `catches` (the exception names its
  handlers catch);
- `domain_errors`: the package's domain error names, sorted;
- `callers`: present only when the call is in a private or nested helper;
  each resolved call site of the helper as `at` (`path:line`), `caller` (its
  qualname) and `envelope` (the caller's `try` and `envelopes`, or null when
  the call sits in neither);
- `privacy`: present with `callers`; why the enclosing function counts as a
  helper: `nested`, `all` (its package's `__all__` leaves it out), `script`
  (a standalone script's function its `__main__` guard does not call) or
  `underscore` (nothing is declared and its name has a leading underscore).

Read the candidate's source. Read the file at `path` when the surroundings
decide the verdict.

## Thresholds

- The envelope translates when a handler covers the call's failure class
  (`OSError` for the filesystem and `open`, `OSError` and
  `subprocess.SubprocessError` for `subprocess`, the library's error or a
  broad handler otherwise) and raises one of `domain_errors`.
- Logging, returning a default or a bare re-raise is not translation.
- A lexical `try` in the function, or a listed envelope, counts.
- A call in a helper marked private, or in a nested function, is also covered
  when every resolved caller in `callers` calls the helper inside a
  translating envelope. A caller with a null `envelope`, or whose envelope
  does not translate, leaves the helper uncovered.
- A helper with no resolved caller is not covered by this rule: judge the
  call on its own envelope, and say in the reason that no caller was found.

A threshold that this brief does not settle is not yours to decide: report
it in your reply, name the candidate, and judge the rest as the brief says.

## Output

Write one JSON line per candidate to the result file you are given, with
exactly these keys:

- `id`: the candidate's `id`;
- `findings`: `{"call": ["what is wrong and the fix"]}` when it is a hit, or
  `{"call": []}` when it is not;
- `reason`: one sentence on why, naming the envelope that covers the call or
  the caller that leaves it uncovered, and the `privacy` rule when the
  helper rule decides the verdict.

Every candidate in the batch gets exactly one line.
